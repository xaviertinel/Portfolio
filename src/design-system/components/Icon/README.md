# Icon

Pictogrammes Flaticon UIcons, style Regular Rounded (et Brands pour LinkedIn et GitHub), insérés en SVG inline.

## Règles

- Un seul style dans tout le site : **UIcons Regular Rounded**. Pas de mélange avec Solid, Bold ou une autre bibliothèque.
- SVG inline avec la classe `xt-icon` : la couleur suit `currentColor`, donc le texte autour (`text`, `primary`…).
- Tailles : `icon-sm` 16px (tags, small), `icon-md` 20px (boutons, nav), `icon-lg` 32px (cartes, sections).
- Icône décorative : `aria-hidden="true"`. Icône seule porteuse de sens : `role="img"` + `aria-label`.
- Contraste d'une icône porteuse de sens : 3:1 mini (WCAG 1.4.11). L'or `accent` ne convient pas en mode clair.
- Les 34 icônes de base sont dans **Assets › Icons**. Pour en ajouter : même style, sur [flaticon.com/uicons](https://www.flaticon.com/uicons).
