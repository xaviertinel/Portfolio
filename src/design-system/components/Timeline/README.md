# Timeline

Raconte le parcours dans l'ordre antichronologique, du poste actuel à la formation.

## Règles

- Liste ordonnée `<ol>` : l'ordre a un sens pour les lecteurs d'écran.
- Date en `font-code` couleur `primary`, titre « Poste · Structure », une ligne de contexte en `xt-small`.
- Le poste actuel prend `xt-timeline__item--current` (pastille pleine `primary-strong`).
- Le fil vertical reprend le dégradé décoratif Morpho : c'est un décor, il ne porte pas d'information.
- 6 étapes max : au-delà, renvoyer vers le CV.

## Ce que fournit le consommateur

Dates, intitulés, structures, une phrase de contexte par étape.
