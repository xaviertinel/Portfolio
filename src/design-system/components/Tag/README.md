# Tag

Étiquette courte qui qualifie un projet : une techno (tag) ou une distinction (badge or).

## Variantes

| Classe | Rôle | Tokens |
|---|---|---|
| `xt-tag` | Techno, compétence, secteur | `tag-bg`, `tag-text`, `radius-pill` |
| `xt-badge` | Distinction forte : prix, lauréat | `badge-gold-bg`, `badge-gold-text` |
| `xt-badge xt-badge--outline` | Distinction secondaire : certification | texte `accent-text`, contour `accent` |

## Règles

- 5 tags max par carte, triés du plus parlant au moins parlant pour un recruteur.
- 1 badge or max par carte : l'or reste rare pour garder sa valeur.
- Pas de tag cliquable sans état de focus et cible de 44px.

## Ce que fournit le consommateur

Le libellé, une icône `xt-icon--sm` optionnelle.
